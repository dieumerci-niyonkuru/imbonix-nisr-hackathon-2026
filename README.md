# IMBONIX

IMBONIX turns Rwanda's published statistics into evidence for financial inclusion and poverty reduction, district by
district. It is an independent team project for the NISR 2026 Big Data Hackathon, Track 2: Financial Inclusion and
Poverty Reduction.

The project arrives here in stages on the `develop` branch: the contribution and security guidelines, the data pipeline,
the API, the web app, deployment, the automated checks and the documentation.
