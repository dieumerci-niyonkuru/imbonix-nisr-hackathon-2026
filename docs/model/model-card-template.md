# Model Card Template

## Model purpose

Describe the vulnerability or outcome estimated by the model.

## Data

List datasets, years, geography, inclusion rules, survey weights and missing-value handling.

## Evaluation

Report baseline, model, holdout period, accuracy, precision, recall, F1, calibration and uncertainty.

## Fairness

Compare performance across sex, age, urban/rural location and other available groups.

## Limitations

Predictions depend on data quality, completeness, representativeness and the stability of relationships across time.
