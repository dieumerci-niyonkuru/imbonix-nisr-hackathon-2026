## Our responsibility

Every statistic shown by IMBONIX comes from a published NISR or partner source cited beside it. **No figure was generated by an AI tool.** The team reviewed the work and is responsible for every figure, claim and line of code in the submission.

## About IMBONIX AI (the in-app assistant)

IMBONIX AI is **not an external LLM**. It is a 947-line TypeScript engine built by the team that runs entirely in the browser with no network call, no API key and no external model. It answers questions only from stored NISR data and **cannot hallucinate** — it returns real published figures or says it does not know. See [IMBONIX AI](../ai-assistant.md) for the architecture.
