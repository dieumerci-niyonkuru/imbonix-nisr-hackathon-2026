# Product Scope

## Product

**IMBONIX Financial Resilience Intelligence Platform**

## Core research question

How can NISR household, poverty, financial-access, labour and social-protection indicators be combined to identify different types of financial vulnerability across Rwanda and support better-targeted interventions?

## MVP

1. District-level indicator dashboard
2. Poverty and financial-access comparison
3. Rwanda geography exploration
4. Evidence-backed signal cards
5. Source and methodology metadata
6. Explainable vulnerability model when authorised data is available

## Boundaries

The system is decision support, not an official classification system, a benefits eligibility engine, or a replacement for NISR publications.
